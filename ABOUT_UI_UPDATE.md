# About / Company Page Update

## Updated sections
- Company hero: "Software built around real business needs."
- Founder visual card with optional team photo; falls back to a branded AM identity when no photo is configured.
- Founder story and positioning.
- Four principles: Practical, Reliable, Transparent, Long-term.
- What We Build capability grid.
- Engineering philosophy flow: Business goal → User needs → Architecture → Development → Testing → Production.
- Curated core technology stack.
- Final Start a Project CTA.

## Data behavior
The About page now loads featured team members from the existing Team API. If an Aftab profile/photo exists in the admin Team directory, the page uses that profile image and role. If no profile is configured, it does not invent a portrait; it uses the branded AM placeholder instead.

## Design direction
The page intentionally uses restrained technical visuals rather than another large 3D marketing scene, keeping the Company page more human and credible while matching the existing DevStak visual system.
