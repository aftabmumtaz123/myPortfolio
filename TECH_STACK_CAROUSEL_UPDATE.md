# Technology Stack Carousel Update

The public single-project case study technology section now uses real React Icons for common stack names and displays the technologies in a single horizontally animated marquee.

- Real icons for React, TypeScript, Next.js, Tailwind CSS, Node.js, Express.js, MongoDB, PostgreSQL, Socket.IO, Cloudinary, Vercel, Railway, Prisma, JavaScript, HTML5, CSS3, Figma, Python, PHP, Git, GitHub and Docker.
- Project technologies are read from the admin-managed project technology relationships.
- The carousel loops continuously and pauses on hover.
- A reduced-motion mode disables the animation and allows horizontal scrolling.
- Unknown technologies fall back to a generic code icon rather than showing an empty icon.
